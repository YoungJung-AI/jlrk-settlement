# Engine Oil Package 3종 바우처 — 테스트 시나리오

3단계(계산 미리보기 / 리테일러 정산확정 / 바우처 생성) 전부 검증하는 순서.
필요 계정: 관리자 1, 리테일러 테스트 계정 최소 1 (기존 `aj-test` 등).

## 0. 준비 — 정산 유형 등록
정산 유형 관리 → [+ 새 유형] (또는 기존 Engine Oil 유형 열기):
- 유형코드: `ENGINE_OIL_PKG` / 유형명: `Engine Oil Package`
- 방향: **AP (지원금 지급)**
- 주기: 월
- 청구 단위: 법인
- 청구금액 산출 방식: **시스템 산출 (리테일러 입력 없음)**
- 부가세 코드: `A0: 0%`
- **원천 엑셀 파싱 규칙 (JSON)** 칸에: `{"preset":"ENGINE_OIL_3V"}`
- 대상 리테일러: 8개사 전체 (비워두면 전체)
- 저장

## 1. 회차 개설 + 계산 미리보기 (1단계)
1. 회차 관리 → [+ 새 회차] → 유형 `Engine Oil Package`, 기간 라벨 예 `FY27 Q2` → 저장 (DRAFT)
2. 회차 클릭 → 상세로 진입 → **원본 2개 업로드칸**이 보임
   - ① 쿠폰 클레임 원본 = `CouponClaim_현황.xlsx`
   - ② 쿠폰북 정산내역 원본 = `쿠폰북정산내역_....xlsx`
3. 두 파일 올리면 아래에 **3종 미리보기 표** 출력:
   - ① 사용반환금 (지점 × JG/LR 고객)
   - ② Retailer Support (지점 × JG/LR VME/Castrol)
   - ③ Sales Incentive (지점 × 판매/환불/최종판매/금액)
   - 상단: 정산대상 건 / 미전송 제외 / 파일 내 중복, 미매칭 지점 경고
   - 하단 검증: 고객 + VME + Castrol 합계 = 총액 (80%+20%)
   **확인 포인트:** 지점별 숫자가 실제 결재본과 맞는지. (기정산 이력이 없으면 전체가 대상이라 총액은 실제 바우처보다 큼 — 정상. Sales Incentive 총액은 원본 그대로면 15,290,000 이 나와야 함)

## 2. 리테일러에 공지 → 리테일러 확정 (2단계)
4. 미리보기 아래 **세금계산서 발행일** 지정 → **[리테일러에 정산내역 공지]** 클릭
   → 리테일러별 claims 생성, 회차 PUBLISHED, (실메일 계정이면) 안내 메일 발송
5. 관리자 회차 상세: **리테일러 확정 현황 표** (확정 0 / N)
6. 로그아웃 → 리테일러 테스트 계정 로그인 → "내 정산"에 카드 뜸
   - 지점별 3종(사용반환금 / Retailer Support / Sales Incentive) + 합계 **읽기 전용**
   - **[정산 확정]** 버튼 → 확인 → "확정완료" 배지
   **확인 포인트:** 그 리테일러 소속 지점만 나오는지, 합계가 미리보기와 일치하는지
7. 관리자로 복귀 → 확정 현황이 갱신됐는지

## 3. 확정 완료 → 바우처 3종 생성 (3단계)
8. 관리자 회차 상세 → **[전체 확정 완료 처리]** (미확인 리테일러 있으면 강제 포함 문구)
   → `settled_records`에 이번 건 지문 기록 → 회차 CONFIRMED
9. **[바우처 3종 생성 (ZIP)]** 클릭
   - 최초 1회: 템플릿 업로드 칸 3개가 뜸 → 아래 파일 업로드 후 다시 클릭
     - ① 사용반환금 = `AP Voucher_..._사용반환금_....xlsx`
     - ② Retailer Support = `AP Voucher_..._Retailer Support_....xlsx`
     - ③ Sales Incentive = `AP without PO_..._incentive.xlsx`
   - ZIP 다운로드: 바우처 xlsx 3개 + `rawdata_통합_*.xlsx`
   **확인 포인트 (엑셀 열어서):**
   - 각 바우처 `AP_input reqeust` 시트에 지점별 금액이 vendor code 행에 바르게 들어갔는지
   - 사용반환금/Support: M열(JG) / N열(LR) 에 값
   - Incentive: I열에 지점별 금액, M/N/합계는 자동 재계산
   - 표지 `AP without PO` 의 Invoice Date(E21), GL 라인 합계(G39~), Total(G53) 이 맞는지
   - Retailer Support 표지 4개 라인: JG 코스트센터에 JG 금액 / LR 에 LR 금액 (원본의 반전 버그가 교정돼 있어야 함)
   - LibreOffice/Excel 에서 열 때 "복구" 경고 없이 열리는지 (recalc 검증)

## 4. 재정산(지연 건) 확인
10. 같은 원본을 새 회차에서 다시 올리면 → 9번에서 확정한 건은 **기정산 제외**로 빠지고
    새로 전송된 건만 정산 대상에 잡히는지

## 알려진 미검증 지점 (3단계)
- 템플릿 셀 매핑은 사용자가 준 FY27 Q2 템플릿 기준으로 작성됨. 셀 위치/시트명이 다르면 값이 안 들어갈 수 있음 → 그런 경우 어느 바우처/셀인지 알려주면 매핑 보정.
- Incentive 템플릿의 I열 빈 셀(수식 없는 지점)은 값이 안 채워질 수 있음(엑셀 XML에 셀이 없으면) → 확인 필요.
- 표지 Invoice Date 서식(날짜 표시) 확인 필요.
